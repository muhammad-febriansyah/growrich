⏺ Analisis Fitur Order PIN & Flow Stokis

  Setelah menelusuri seluruh codebase, berikut temuan saya:

  ---
  Yang Sudah Ada (Working)

  ┌──────────────────────────────────────────────┬────────┐
  │                     Flow                     │ Status │
  ├──────────────────────────────────────────────┼────────┤
  │ Member order PIN (registrasi & upgrade)      │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ Pembayaran via Duitku (auto-generate PIN)    │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ Pembayaran manual transfer + upload bukti    │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ Admin konfirmasi order → generate PIN        │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ Admin tandai dikirim                         │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ Admin batalkan order                         │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ Member lihat stok PIN                        │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ PIN dipakai untuk registrasi/upgrade         │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ Admin generate PIN manual & assign ke member │ ✅     │
  ├──────────────────────────────────────────────┼────────┤
  │ Export Excel                                 │ ✅     │
  └──────────────────────────────────────────────┴────────┘

  ---
  Yang KURANG / Belum Ada

  1. Member Tidak Bisa Transfer PIN ke Member Lain

  Saat ini PIN yang dibeli langsung assigned_to = pembeli. Tidak ada fitur untuk member mentransfer/menjual PIN ke downline-nya. Field assigned_to sudah support ini, tapi UI dan endpoint-nya belum ada.

  2. Tidak Ada Konsep "Stokis" Formal

  Sistem belum punya role/flag Stokis — member yang beli PIN dalam jumlah besar lalu distribusikan ke jaringannya. Saat ini semua member sama.

  3. Tidak Ada Riwayat Perpindahan PIN

  Ketika admin assign PIN ke member lain, tidak ada audit trail — siapa memindahkan ke siapa dan kapan.

  4. Tidak Ada Notifikasi

  - Member tidak diberitahu ketika order-nya dikonfirmasi admin
  - Member tidak diberitahu ketika order ditandai dikirim
  - Tidak ada email/push notification
  -notif pakai email mailketing bisa kamu cek sudah ada 

  5. Tidak Ada Tracking Number Pengiriman

  shipped_at hanya timestamp. Tidak ada field untuk nomor resi atau kurir yang dipakai.

  6. Tidak Ada Harga Stokis / Diskon Volume

  Semua member beli PIN dengan harga yang sama. Belum ada mekanisme harga khusus untuk stokis atau diskon beli dalam jumlah banyak.
